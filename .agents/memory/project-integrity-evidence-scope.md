---
name: Project integrity evidence scope
description: Distinguishes organization-level evidence from project-specific readiness confirmation.
---

Organization-level documents, Pancek progress, and blueprints are supporting inputs only. They must not automatically mark a project control complete; project readiness requires an explicit confirmation tied to the selected project.

**Why:** A reusable policy or checklist may exist without being applied to a specific contract, vendor set, or project team. Counting it automatically produces misleading readiness scores.

**How to apply:** When adding project controls, show relevant organization evidence as review material, then persist the project's own confirmation or assessment before awarding completion credit.
